# Iseler Autoteile – Website

Erster Website-Entwurf für Iseler Autoteile in Heusenstamm.

## Projektstand
- One-Pager, responsive, Light-/Dark-Mode
- Struktur: Unternehmen, Leistungen, Kontakt
- Rechtsseiten als klar gekennzeichnete Platzhalter
- WhatsApp, Logo, echte Mitarbeiterfotos, Kontakt- und Unternehmensdaten werden nachgeliefert
- Bereit für spätere Shop-Anbindung (nicht Teil des aktuellen Scopes)

## Zusammenarbeit
Das GitHub-Repository und dieser Projektstand sind die gemeinsame Quelle für Hermes, Claude und Codex. Dauerhafte Projektfakten werden zusätzlich in OpenViking dokumentiert.

## Vorschau
GitHub Pages wird bei jedem Push auf `main` veröffentlicht.
